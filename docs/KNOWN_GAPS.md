# Known Gaps

These are intentionally not solved unless a later project step explicitly asks for them:

- No real login yet; farmers are identified by an id and this must be solved before a real pilot.
- Worker consent is currently only a boolean.
- The worker reply channel is not chosen; the notifier only logs to the console.
- Admin access uses a temporary `X-Admin-Key` header.
- Labour need in Bihar remains a hypothesis to validate with real farmers.
- Prices, support price, and crop calendar data are provisional until their sources are verified.
